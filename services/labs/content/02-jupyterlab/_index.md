# Lab 2 — JupyterLab

**Interactive exploration and prototyping.**

JupyterLab is where ideas become code before they become pipelines. You use it to understand your data, prototype models, and produce visualisations that inform every decision downstream.

By the end of this lab you will have:
- Explored the MNIST 1D dataset interactively with plots and statistics
- Understood what makes a 1D sequence look like a digit
- Run the full CRISP-DM example notebook end to end
- Seen how MLflow captures experiment results from a notebook automatically

**Services needed for this lab:** JupyterLab and MLflow.

```bash
./scripts/start.sh mlflow
./scripts/start.sh jupyterlab
```
